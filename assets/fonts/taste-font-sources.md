# Typeface sources

Locally hosted Latin subsets for the Taste layout. Retrieved November 9, 2026.

All three families are licensed under the SIL Open Font License 1.1. The original license files accompany the fonts.

- `gabarito.woff2`: https://fonts.gstatic.com/s/gabarito/v9/QGYtz_0dZAGKJJ4t3HtoW4U.woff2
- `figtree.woff2`: https://fonts.gstatic.com/s/figtree/v9/_Xms-HUzqDCFdgfMm4S9DQ.woff2
- `dm-mono-400.woff2`: https://fonts.gstatic.com/s/dmmono/v16/aFTU7PB1QTsUX8KYthqQBA.woff2
- `dm-mono-500.woff2`: https://fonts.gstatic.com/s/dmmono/v16/aFTR7PB1QTsUX8KYvumzEYOtbQ.woff2
- `gabarito-OFL.txt`: https://raw.githubusercontent.com/google/fonts/main/ofl/gabarito/OFL.txt
- `figtree-OFL.txt`: https://raw.githubusercontent.com/google/fonts/main/ofl/figtree/OFL.txt
- `dm-mono-OFL.txt`: https://raw.githubusercontent.com/google/fonts/main/ofl/dmmono/OFL.txt

Gabarito and Figtree use variable weight files. DM Mono uses separate regular and medium files. Existing typefaces are retained for compatibility.
